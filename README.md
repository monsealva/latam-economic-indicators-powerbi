# latam-economic-indicators-powerbi
An interactive Power BI dashboard analyzing the 10-year correlation between GDP, unemployment, and poverty across Latin America. Please note that this visualization is presented in Spanish

## Overview
This project aggregates complex socioeconomic datasets to explore the dynamic relationships between GDP growth, unemployment rates, poverty levels, and foreign direct investment. By moving beyond static reporting, this tool allows users to visually track the regional economic impact of global events over a 10-year period.

## Key Features
* **Animated Time-Series Analysis:** Features a dynamic scatter plot with a Play Axis, animating the correlation between Unemployment and GDP Growth from 2014 to 2025 to visualize economic shifts (such as the 2020 contraction).
* **Geospatial Mapping:** Interactive maps with customized tooltips breaking down population demographics (Male vs. Female) by region.
* **Granular Disparity Tracking:** Grouped bar charts segmenting poverty rates by National, Urban, and Rural areas across major LATAM economies (MX, COL, ARG, BRA, etc.).
* **Investment Treemaps:** Proportional visualization of Millions in Foreign Direct Investment by country.

## How to View
Since Power BI public web-publishing is restricted by tenant settings, you can interact with this dashboard by:
1. Downloading the `.pbix` file from this repository.
2. Opening it locally using **Power BI Desktop**.
